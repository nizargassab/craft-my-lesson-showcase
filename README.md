# Craft My Lesson

A SaaS platform that helps teachers turn their own images into personalized classroom activities and print-ready PDFs. The creation flow brings together activity selection, image uploads, editable options, previews and downloads.

**My role:** Freelance Full-Stack Developer  
**Author:** [Nizar Gassab](https://github.com/nizargassab)

[View project](https://craftmylesson.com/) · [Portfolio case study](https://nizar-gassab-portfolio.vercel.app/projets/craftmylesson/) · [LinkedIn](https://www.linkedin.com/in/nizar-gassab-b872b5244/)

## What I worked on

### 1. Resource generation

Developed the Python/FastAPI generation workflow and the React interface for creating customized printable resources.

### 2. Accounts and access

Implemented JWT authentication and role-based access across user and administration workflows.

### 3. Credits and payments

Integrated Paddle payments and credit accounting with idempotent webhooks, so replayed payment events do not grant credits twice.
